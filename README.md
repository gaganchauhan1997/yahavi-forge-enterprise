# Yahavi Forge Enterprise

**AI Career OS** — 17 tools, BYOK (Bring Your Own Key), free to start.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Supabase Auth + Database
- Multi-AI provider support (Groq, Gemini, OpenRouter)

## Tools (17)

**BUILD** (Free tier): Resume Builder, Bullet Upgrader, Portfolio Generator, Gap Framer, Achievement Forge
**ANALYZE**: ATS Scorer (no key needed), Recruiter Scan, Resume Roast
**TAILOR**: JD Tailor, Truth-Lock Tailor, Company Tailor
**OUTREACH**: Cover Letter, Recruiter Hook, Application Pack
**STRATEGY**: Role Fit Finder, App Optimizer, Interview Prep

## Getting Started

```bash
npm install
npm run dev
```

Add your API keys in the KEYS panel to start using AI-powered tools.
